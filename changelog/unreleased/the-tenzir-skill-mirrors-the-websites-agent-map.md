The `tenzir` skill is now a copy of the agent map that tenzir.com publishes with every documentation release, together with the pages it links. It matches the documentation of the latest release exactly. Integrations and pages that ship on their own schedule, such as the platform and the test framework, are now linked on the website instead of bundled.
