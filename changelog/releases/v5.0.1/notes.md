This patch release makes data file references in the Open Cybersecurity Schema Framework skill clickable links. It also refreshes the synced Tenzir skill and schema data.

## 🐞 Bug fixes

### Markdown links for OCSF data files

The `tenzir-ocsf` skill's Data files table now formats concrete versioned file paths as standard Markdown links (such as `version.yaml`, `changelog.md`, `classes.yaml`, and `objects.yaml`), matching the other schema skills.
