## 💥 Breaking changes

### The tenzir skill covers Tenzir 7

The `tenzir` skill now follows the default documentation at tenzir.com/docs, which is Tenzir 7. Install `tenzir/skills@tenzir` to get it; the `tenzir-7` branch with the preview skill is gone.

If you still run Tenzir 6, point your agent at the documentation of your release instead, such as `https://tenzir.com/docs/v6.22.0/SKILL.md`.
