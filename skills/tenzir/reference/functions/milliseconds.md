# milliseconds

> Converts a number to equivalent milliseconds.

Converts a number to equivalent milliseconds.

```tql
milliseconds(x:number) -> duration
```

## Description

This function returns milliseconds equivalent to a number, i.e., `number * 1ms`.

### `x: number`

The number to convert.
