# minutes

> Converts a number to equivalent minutes.

Converts a number to equivalent minutes.

```tql
minutes(x:number) -> duration
```

## Description

This function returns minutes equivalent to a number, i.e., `number * 1min`.

### `x: number`

The number to convert.
