# Overview

> Match security activity and model the resulting findings.

Detection turns normalized events into findings by matching activity, measuring behavior over time, and correlating independent signals.

Start with [matching events in TQL](https://docs.tenzir.com/guides/match-events-with-tql) and [modeling the resulting OCSF findings](https://docs.tenzir.com/guides/model-detections-in-ocsf). Then explore [time-window detection](https://docs.tenzir.com/guides/detect-over-time-windows), [stored-event baselines](https://docs.tenzir.com/guides/baseline-from-stored-events), [periodic-behavior detection](https://docs.tenzir.com/guides/detect-periodic-behavior), [multi-stage detectors](https://docs.tenzir.com/guides/create-multi-stage-detectors), [Sigma](https://docs.tenzir.com/guides/execute-sigma-rules), and [YARA](https://docs.tenzir.com/guides/scan-bytes-with-yara).
