# Overview

> Deliver event streams to the systems that need them.

Routing sends events to destinations, connects pipelines, and splits one stream across independent processing paths.

Learn how to [send data to destinations](route/send-to-destinations.md), [split and merge streams](route/split-and-merge-streams.md), [fan out with subpipelines](route/fan-out-with-subpipelines.md), [load-balance pipelines](route/load-balance-pipelines.md), and [expose pipeline data as a server](route/expose-data-as-server.md).
