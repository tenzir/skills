# Overview

> Turn event streams into summaries and statistics.

Aggregation combines events into compact records that describe counts, distributions, and other statistics over a stream.

Learn how to [aggregate event streams](https://docs.tenzir.com/guides/aggregate-event-streams), [window streams](https://docs.tenzir.com/guides/window-event-streams), [shape aggregation results](https://docs.tenzir.com/guides/shape-aggregation-results), and [calculate aggregate statistics](https://docs.tenzir.com/guides/calculate-aggregate-statistics).
