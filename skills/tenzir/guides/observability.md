# Overview

> Inspect node, pipeline, and host behavior.

Observability shows how a node and its pipelines behave while they run. Use logs, diagnostics, and metrics to understand current state before changing a pipeline or investigating a failure.

Start by learning how to [inspect a node](observability/inspect-a-node.md), then [collect node and pipeline metrics](observability/collect-metrics.md) for continuous monitoring.
