# Overview

> Diagnose pipeline failures, resource growth, and node connectivity.

Troubleshooting starts with the symptom you can observe, then narrows the problem to a pipeline, operator, or connection.

Use these guides to [debug unexpected field values](https://docs.tenzir.com/guides/debug-field-values), [investigate slow pipelines](https://docs.tenzir.com/guides/investigate-slow-pipelines), trace [memory](https://docs.tenzir.com/guides/investigate-memory-growth) or [storage growth](https://docs.tenzir.com/guides/investigate-storage-growth), and [reconnect an offline node](https://docs.tenzir.com/guides/reconnect-an-offline-node).
